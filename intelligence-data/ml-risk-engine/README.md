# ML / Risk Engine — Person 3 (Ayush)

PS 26002 — Accessibility Risk Score model for the Guwahati-Itanagar corridor.

## Structure

```
ml-risk-engine/
├── data/
│   └── processed/
│       └── road_risk_data_relabeled_noisy.csv   # training input (from Person 4's raw data + relabeling)
├── scripts/
│   └── train_risk_model.py                      # trains all models, exports everything below
├── outputs/                                      # all auto-generated by train_risk_model.py
│   ├── accessibility_risk_model.joblib           # the trained, calibrated model
│   ├── road_risk_scores.csv                      # risk score (0-100) per road_id
│   ├── model_input_schema.txt                    # exact input columns the model expects
│   └── model_report.txt                          # metrics, feature importance, threshold sweep
└── predict_risk_score.py                         # handoff function: predict_risk(rows) -> risk scores
```

## How to run

```bash
cd ml-risk-engine
python scripts/train_risk_model.py
```

Reads `data/processed/road_risk_data_relabeled_noisy.csv`, writes everything in `outputs/`.

## For the backend/routing team

Use `predict_risk_score.py` — call `predict_risk(rows)` with road feature data
(see `outputs/model_input_schema.txt` for the exact columns). No API/backend
code is included here on purpose — that integration is out of this role's scope.
